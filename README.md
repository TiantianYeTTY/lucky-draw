# lucky-draw

> 一个零依赖、单 HTML 文件的老虎机抽奖网页。设置 0~999 的编号范围，拉动拨杆，三位数字轮盘依次旋转、过冲回弹定格，开出完全随机的编号——005、010、242、651……
>
> 随机数使用 `crypto.getRandomValues` 密码学级随机源 + rejection sampling，保证结果在编号范围内均匀分布、完全随机；所有数据仅存在本地，不上传任何东西。
>

## ✨ 这是什么

课堂点名、年会抽奖、直播开奖，最怕的是「随机性看不见、观众不服气」：要么用 Excel 随机函数毫无仪式感，要么在线抽奖工具夹私货、要登录、还弹广告。

`lucky-draw` 把开奖做成一台**看得见随机性**的网页老虎机：

- 拨杆拉下 → 三位数字依次高速旋转 → 左到右逐位刹停（先冲过目标 2 格再弹回），悬念拉满；
- 中奖编号定格后自动补齐 3 位（如 `005`、`010`），与「0~999 编号」的直觉完全对齐；
- 全部逻辑在浏览器本地运行，**单 HTML 文件**，双击即用，无需安装、无需联网、无任何依赖。

核心能力：

- **编号范围自由设置**：起始 / 结束编号输入框（0~999 任意区间），非法值红框提示，实时更新编号池信息；
- **完全随机**：`crypto.getRandomValues` + rejection sampling，结果均匀分布，不是 `Math.random` 级别的伪随机；
- **不重复抽取开关**：开启后抽过的编号从编号池移除，已抽编号永不重复，池空自动提示重置；
- **开奖记录**：最新一条高亮展示，点击任意记录一键复制编号，随时回看；
- **仪式感动画**：拨杆 3D 拉下回弹、数字轮盘过冲刹车、中奖结果条红橙渐变 pop；
- **响应式**：桌面端拨杆在机身右侧，窄屏（≤560px）自动移到数字窗口下方居中，手机也能玩。

## 🚀 使用方法

1. **设置编号范围**：在「起始编号」「结束编号」输入 0~999 之间的值（默认 0 ~ 999），非法输入会被红框提示并拦截。
2. **按需开启「不重复抽取」**：开关打开后，抽中的编号自动移出编号池，已抽编号永不重复；编号池抽完会提示重置。
3. **拉动拨杆开始抽奖**：点击右侧拨杆，或按键盘空格键——三位数字依次旋转刹停。
4. **看结果**：中奖编号定格显示（自动补齐 3 位），同时计入底部「开奖记录」，最新一条高亮。
5. **复制 / 回看**：点击任意历史记录 chip 即复制该编号；「重置记录」清空全部历史并重置不重复编号池。

## 🔧 技术实现

- **均匀随机**：`crypto.getRandomValues(Uint32Array)` + rejection sampling，消除取模偏差；
- **轮盘动画**：每列 220 格数字条，CSS `transform: translateY` 双段 transition——先高速滚过目标，再回弹 2 格刹停，复刻真机老虎机的机械感；
- **三位依次停止**：1.4s / 2.0s / 2.5s 递增时长，逐位点亮窗口边框；
- **拨杆**：CSS 3D `rotateX` + `perspective`，拉下后带弹性回位；
- **前导零**：`padStart(3, '0')`，任意结果对齐三位显示。

## ⚠️ 重要说明

1. **抽奖公平性**：随机源为浏览器密码学 API，刷新页面不会影响已抽记录的统计；但「不重复抽取」的编号池存在内存中，**刷新页面会丢失历史记录**，长流程抽奖请勿中途刷新。
2. **范围变更**：修改起始/结束编号会同时清空开奖记录与不重复编号池（旧编号不属于新池）。
3. **本地运行**：文件不请求任何外部资源、不上传任何数据，可放心离线使用。
